---

## 📌 Project Overview
This repository contains the full engineering blueprint for restructuring quality operations from disjointed, spreadsheet-heavy workflows into a highly integrated, standard-compliant digital quality pipeline. The system tracks structural integrity parameters and manages regulatory compliance thresholds from incoming raw components up to final hydrostatic load verification.

* **Main Document:** [`docs/final.docx`](docs/final.docx)
* **Target Manufacturing Context:** Vacuum-Insulated Cryogenic Static/Transport Vessels
* **Applicable Codes:** ASME Section VIII Div. 1, ISO 21009, ISO 2859-1, and ISO/IEC 25012
